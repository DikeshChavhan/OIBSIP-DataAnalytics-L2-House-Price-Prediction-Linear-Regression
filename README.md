# 🏠 House Price Prediction using Linear Regression

## 📌 Project Overview

This project demonstrates an end-to-end Machine Learning workflow for predicting house prices using **Linear Regression**. It covers the complete data science pipeline, including exploratory data analysis (EDA), data preprocessing, feature engineering, model training, evaluation, visualization, and model interpretation.

The project is implemented in **Python** using the **scikit-learn** library and follows industry-standard machine learning practices.

---

## 🎯 Objective

Develop a Linear Regression model to predict house prices based on various property features while understanding the impact of each feature on the final prediction.

---

## 🚀 Features

* ✅ Exploratory Data Analysis (EDA)
* ✅ Data Cleaning and Missing Value Handling
* ✅ Feature Selection
* ✅ One-Hot Encoding for Categorical Features
* ✅ Correlation Heatmap
* ✅ Train-Test Split (80/20)
* ✅ Linear Regression Model
* ✅ Model Evaluation using:

  * Mean Squared Error (MSE)
  * Root Mean Squared Error (RMSE)
  * R² Score
* ✅ Actual vs Predicted Price Visualization
* ✅ Residual Analysis
* ✅ Feature Coefficient Analysis
* ✅ Ridge Regression Comparison
* ✅ Lasso Regression Comparison

## 📊 Machine Learning Workflow

1. Load Dataset
2. Perform Exploratory Data Analysis (EDA)
3. Handle Missing Values
4. Encode Categorical Features
5. Perform Correlation Analysis
6. Split Dataset into Training and Testing Sets
7. Train Linear Regression Model
8. Predict House Prices
9. Evaluate Model Performance
10. Visualize Results
11. Interpret Feature Importance
12. Compare with Ridge and Lasso Regression
